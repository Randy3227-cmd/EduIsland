# Image requise pour Géométrie Niveau 2

## Fichier à créer
- **Chemin**: `eduisland/public/images/formes_geometriques.png`
- **Type**: Image PNG avec fond clair (blanc ou beige clair)
- **Dimensions recommandées**: 450px x 500px

## Contenu de l'image

L'image doit contenir 4 formes géométriques colorées disposées ainsi:

### Position des formes (coordonnées du centre):

1. **Carré bleu** 
   - Centre: x=150, y=120
   - Taille: environ 60x60 pixels
   - Couleur: bleu (#3B82F6)

2. **Cercle rouge**
   - Centre: x=300, y=120
   - Rayon: environ 35 pixels
   - Couleur: rouge (#EF4444)

3. **Triangle vert**
   - Centre: x=225, y=250
   - Base: environ 70 pixels
   - Couleur: vert (#10B981)

4. **Rectangle jaune**
   - Centre: x=150, y=380
   - Dimensions: environ 80x50 pixels
   - Couleur: jaune (#F59E0B)

## Notes
- Les zones cliquables ont un rayon de 40 pixels autour de chaque centre
- Ajouter un léger ombrage pour un effet 3D (optionnel)
- Fond clair pour bien contraster avec les formes
- Style simple et adapté aux enfants d'école primaire

## Création rapide
Vous pouvez créer cette image avec:
- Un éditeur graphique (Photoshop, GIMP, Figma)
- Du code SVG puis export en PNG
- Un outil de génération d'images en ligne

## Alternative temporaire
Pour tester sans créer l'image, vous pouvez utiliser une image placeholder:
